Place Extras gallery images here as .png files.

Name each file with letters, digits, _ or - only, for example concept_1.png.
Each side must be 4096 pixels or less. Run Project > Prepare & Check in the
Defold editor, then add an entry to gallery.entries in developer/config/extras.lua
whose image is the file name without .png.
Reset Project to Empty removes these images and restores this empty folder.
