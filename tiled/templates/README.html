MVTK Tiled Templates Reference

Generated from the 85 live tiled/templates/**/*.tx files. Each table mirrors the Tiled Properties panel and adds a Comments column.

New to Tiled or Defold? Start with the complete creator guide; use this page when you need every property and default.

Identity selectors and required IDs stay at the top level; related tuning is collected into one-level collapsible groups. Existing maps with flat overrides remain compatible. Newly placed templates already include the grouped properties; no upgrade step is needed.

Template presets

Select one toolkit template object on the top-level templates layer of a saved room. Choose File > Save as Template Preset..., enter a lower-case name and keep the suggested external presets folder, then click OK. Drag the saved .tx from the Project view into any room. Edit the .tx in the Template Editor to change every placement that inherits those values. To update from a tuned preset placement, choose Save as Template Preset... and confirm the overwrite. Save affected rooms, export them, then run Project > Prepare & Check in Defold before building. Presets stay outside the toolkit with original maps and art; choose Project > Add Folder to Project... if the folder is missing from the Project view. Enemy Art links are kept relative to the preset's folder. Placement IDs and object links reset; place presets by hand to replace existing objects. Per-placement overrides keep their values. A base-version warning asks you to update the preset; there is no Refresh command. Preset placements bake into editable gameobjects in the room collection.

Carts and gondolas

Moving Platform > vehicle opts into throttle carts or auto gondolas on named Path polylines. Draw both tracks through open space inside one room. Vehicle max speed is px/s; acceleration, brake and drag are px/s squared. Throttle projects held stick axes onto the track; riders do not walk by default and Jump leaves. Auto starts with a player aboard. End stop holds; return goes home after the empty delay; fall_away falls for one second, hides and reappears after that delay. Vehicle alt path starts on the first track within 2 px. A Lever or Strike Switch Target id names Vehicle switch id as text: turn it on before the forward junction to take the second track. A Target object reference selects activation instead. Backing past the branch start rejoins the main track. Persist state saves the switch channel only; vehicle positions are not saved. Pause freezes motion and timers. Player parent must be ticked to carry the rider. Tick Vehicle float for a raft: its top sits Vehicle float offset pixels above the water surface (default 16), and its bottom never drops below the track. Draw the track at the drained basin floor. Empty, or with a throttle rider giving no input, a floating raft eases at Vehicle acceleration into a drift along the track in the matching current direction at Current strength, capped by Vehicle max speed, and responds to live current changes; an auto raft keeps running while it has a rider. Water-level switches lift and lower it. Prepare & Check warns raft_without_water when neither track crosses a Water Volume. Keep the whole rider clear at every level.

Moving hazards

Hazard > Path motion adds line, path, orbit and slam movement. Motion path ref picks a visible unrotated polyline outside templates; Motion pivot ref picks a point there. Line/Path speed is pixels per second; Orbit speed is degrees per second (negative clockwise). Positive Motion distance y is down. Motion offset is a timing offset in seconds. Pingpong waits at both ends; loop closes a Path; once holds at the far end. Slam warn/rest inherit crusher warn_time/crush_hold_time at -1; its sound_warn, sound_crush and particle_on_crush play at warning/impact. Use linked object art, as painted room tiles stay still. Pause or a disabled switch channel freezes movement; activation resumes. Safe returns avoid the whole sweep; add a Hazard Return Zone in tight rooms. Arena settings: boss_ref and arena_ref select objects; arena.boss_id and arena.arena_id are string alternatives. Boss phase 1 is the first fight phase. Empty Active phases means the whole fight. Set none for pulse only. A boss pulse can name particular placed hazards by Hazard ID. At a rage, desperation or shield phase change, Boss Phase > Transition effects > Spawn hazards briefly pulses the arena's pulse-only hazards of the selected type. Crystal Golem's shield phase uses spikes. If Prepare & Check reports an unknown type, choose a type from hazard_types.lua. If it reports an unknown Hazard ID, link that placed Hazard to the arena or correct the pulse attack's list. Hide when inactive hides collision and art for the arena gate only. Warn time blinks harmlessly before a phase turns the hazard on. A pulse sets its own harmless blink. Boss links stop at defeat; arena-only links stop at unlock after cleanup. Level hazards ignore Arena settings.

Carry and throw objects

Place Physics > Carryable on templates. Interact picks up or drops; Attack throws and Up + Attack throws high. Kind comes from carry_settings.lua: crate damages enemies, orb sends puzzle hits, bomb starts its fuse at pickup. Handling > Move speed mult is 0.25 to 1; Blocks jump makes a heavy object. Fragility controls breaks and fuse seconds. Water, climb, ledge hang and stun drop it; room changes and lost/broken objects return home. Carrying blocks combat, dash, slide, Blink, backdash, ground pound and grapple. Linked object art replaces the manual-sized placeholder. Keep the whole throw arc and bomb blast clear. Bomb fruit can open bomb walls without Bomb: add progression_links. Interaction > Socket accepts a dropped or thrown Carryable. Acceptance filters Kind or an exact Carry id. Target reference chooses a same-map receiver; Target id names a channel. Response > Persist state consumes the object permanently and saves the filled socket and channel; otherwise Take hands it back and sends off. Set flag on means ever filled and never clears. Link empty and filled art_state images to the socket. Strike Switch > Behavior > Accepts = thrown accepts crate and orb impacts tagged throw.

Movement zones

Place Environment > Movement Zone on templates. Preset selects low_gravity, heavy, sticky or sinking from movement_zone_types.lua; overrides use -1 to inherit. Overlapping zones keep the strongest value per key. Jump scales velocity after High Jump, so height scales with jump_mult squared / gravity_mult: leave the full player and ascent clear of ceilings, hang bars and hazard sweeps. Wall jumps, ladder jump-off and grapple launches remain unscaled; glide/swim retain their fall caps. Put a floor or Hazard below sinking pools and press Jump repeatedly to escape. Movement zone id is the text switch target; Enabled sets the initial state and persistent switch channels replay on room load.

Hang bars and climb meshes

Use Navigation > Ladder for every climb kind. Resize a hang_bar wide and short; hang_speed controls sideways travel, drop_on_down allows Down release, and can_jump_off allows Jump to let go without an upward launch. A climb_mesh moves in eight directions at climb_speed. Both ignore snap_to_center; hang_bar also ignores pass_through_top. Vertical ladder, vine, rope and chain keep their existing behavior. Configure hang_idle_animation, hang_move_animation (both hang by default) and optional mesh_animation in player_settings.lua > ladder_climb.

Elevators with several floors

Elevator route_axis defaults to vertical; horizontal builds a tram through matching side doors. Horizontal nodes share lane Y; left/right alias bottom/top, and held Left/Right selects stations. Side doors contain cabin height plus shaft_clearance above and below; leave extra rider headroom. camera_lock_x locks lane Y for a tram. Elevator Node uses stop bottom, top or middle for floors; pass_through nodes use none. Keep one bottom and one top in different rooms, with middle floors strictly between them. landing_label is an optional floor name. Elevator > activation > destination_mode next visits the next floor and reverses at the ends; direction waits for an aboard rider to hold Up or Down; choose waits for Interact and opens a paused floor list with the current floor disabled. Lever and Strike Switch > messages use message_on elevator_call plus call_landing set to that floor's node_id. Saved cabins restore their last completed floor, never a mid-shaft position. See the creator guide's Add a middle floor, Call the elevator to a floor and Let the rider choose a floor recipes.

Saved shortcuts

For a saved shortcut tick Lever > conditions_and_flags > Persist state or Pressure Plate > response > Persist state. A persistent plate stays pressed. Timed Door > behavior_and_timing > Stays open keeps every opening permanent. Use a unique door_id unless several rooms should restore the same channel. Set a switch's target_ref to a door or Moving Platform; a blank platform trigger_id is generated. Matching target_id/trigger_id text also works. Doors, painted platforms and hazards restore saved channels on room load. Call and momentary levers ignore Persist state; leave it off for ordered puzzles. Momentary levers set Set flag on but load off, and start-open doors load silently. Prepare & Check reports shared channels.

Switch gates

Choose Gate > gate_type = switch_gate and give it a unique gate_id. Point a lever or plate target_id at that id (target_ref works in the same room). State and persistence > Stays open saves the opening as gate_<id> and opens its gate group; with Stays open off, ON opens temporarily and OFF closes, without group propagation. Tick Persist state on the sender for unloaded-room replay. Prepare & Check warns if no switch targets the gate.

Player and world elements

Hazard Elements > Damage type inherits its preset when none; Pendulum Hazard Damage and knockback > Damage type uses slash when none. Water Volume sends water_types damage to players and enemies. Breakable Wall Durability > Required damage type accepts an exact type or its family, independently of Required ability. The empty toolkit has physical player attacks and no infusion. Add an ordered player_attack_infusions row in damage_types.lua and unlock its ability to infuse attacks; the first unlocked row wins. Analyze Progression includes matching infusion abilities for annotated walls, or reports unknown when no attack emits the type. sample_map5 helper 604 tt_breakable_fire uses a sprite with swap_tiles_on_break=false and no painted tiles.

One-sided walls

Breakable Wall > durability > break_from chooses any, left, right, above or below. Any keeps ordinary hits; another side refuses damage and plays developer/config/switches.lua blocked_hit_sound. Shots and bombs use the player position, not their projectile or blast position. Explosion messages bypass this rule. Position-side classification uses swap_width/height as the wall bounds; tile-swap overrides therefore also affect diagonal hits.

Gate groups

Set Gate > state_and_persistence > Group id (group_id) to the same text on each gate that should open together, including gates in other rooms. Leave Persist unlock enabled to save the shared opening. Only persistent openings propagate; temporary openings do not. A blank group_id keeps a gate independent. Keep group ids stable after release so saves retain their opening. Prepare & Check reports a group used by only one gate. Export every changed room, prepare and build, then test cross-room travel, save/load and both open map icons.

Staged gates

Choose Gate > gate_type = staged_gate. In stages, set stage_flags to comma-separated saved flag names and stages_required to the count needed (-1 = preset, 0 = all listed). Levers write conditions_and_flags > set_flag_on, including momentary levers (switching > toggle off); plates write response > set_flag. Leave switch target_id blank. Flags count in any order across rooms and are never cleared by switching off. Partial progress survives reloads and saves, unlike ordered sequence progress; the proximity hint shows n/N. Keep state_and_persistence > persist_unlock on to save the opening. Prepare & Check warns about empty or unwritten flags and rejects a count above the list length.

World state

World state > appear_when and remove_when make an object come and go with story progress. They are on NPC, Collectible, Ability Pickup, Key, Chest, Lore Item, Map Fragment, Sign, Hint Stone, Map Marker, Dialogue Trigger, Teleporter, Save Point, Gate, Locked Door, Breakable Wall, Light Source and Torch; any other baked object may carry the same names as plain custom properties. A condition is a comma list that must all hold: flag, !flag, ability:<id> or item:<id>[:n], with | joining alternatives inside one term, for example met_hermit, ability:dash|ability:grapple. Blank or none means always. presence_timing enter applies a change the next time the room is built, which happens as soon as the player is not inside it; live removes the object at once. Create Rooms bakes an <id>__presence companion beside the object. Removing a Breakable Wall object does not remove its painted wall tiles. Rebuilding a stale room also revives enemies whose respawn is room_reload. Prepare & Check reports conditions that do not parse and flags nothing writes.

Encounters

Encounter and Encounter Spawn bake as editable gameobjects. Their scripts currently register settings only: no fight, seal, wave or clear reward runs yet. Place points inside the rectangle or set Encounter ref; an unset link uses the smallest containing rectangle.

Boss encounters

A Boss, Boss Phase and Boss Arena each bake into an editable gameobject in the room collection. Change a script property in Defold, save the collection and choose Build to try it. Export the room from Tiled again and run Prepare & Check to restore the Tiled values.

On a Boss, Ground motion set to On makes it follow the floor. Shipped walking types enable it. The type_default choice follows the boss type. Feet offset is the distance in pixels from the boss centre to its feet. At zero it inherits the boss type's offset or measures from the placed centre to the floor.

A Boss Phase uses seconds of play. Telegraph scale changes the warning time and Cooldown scale changes the wait before reuse. A floor slam's dodge height is measured from the floor to the player's feet. Give a phase an attack that reaches raised platforms if its floor attacks leave a gap in height coverage.

A Boss Arena holds the whole collision body of a boss with Ground motion off when there is room. If Prepare & Check reports a body outside, move the boss inward. If the body cannot fit, enlarge the arena or reduce the boss type's size. If an attack cannot fit, give it more room, narrow its safe gap, or pick another.

Bar name (bar_name) sets the translated health-bar title. Blank uses the object Name unless it is blank, Boss or Boss Spawn, then the preset name when set, then the boss id. A shared bar uses the arena's group_name or the lead boss's name when that field is blank.

Linked enemy art

Enemy art can be linked with the optional art file property. Select a numbered frame such as enemies/ghost_enemy/idle_01.png outside the Defold project, then Export Current Room. Export copies the skin folder and Prepare & Check syncs it. enemy_type chooses synced art; Archetype chooses stats and behaviour from developer/config/enemy_types.lua independently. none preserves the matching preset, or enemy_defaults.default_archetype for art-only ids. Prepare & Check refreshes Archetype choices; reopen the Tiled project afterwards. Archetype turret supplies stationary aimed_shot attacks. movement_and_attacks.aim_mount selects free, floor, ceiling, wall_left or wall_right; type_default inherits the archetype. Lead, turn rate, tolerance and bursts are configured in enemy_types.lua with enemy_defaults.lua fallbacks. Terrain blocks shots by default. Archetype spike_shell supplies stationary spike_cycle attacks: exposed, warning, then armed with a guard and increased contact damage. tuning.spike_offset advances the cycle in seconds to desynchronize placements. Timings and the armed contact factor are configured in enemy_types.lua with enemy_defaults.lua fallbacks. Shield and armed shells block direct hits with sound, flash and a translated BLOCK label when Damage numbers is on; damage over time bypasses the guard. Attacker impact feedback still plays. Blank art keeps the selected skin. Legacy enemy_templates.lua archetypes are a separate spawn API. Enemy Stats > Ledge behaviour selects type_default, stop, fall or fall_when_chasing. type_default inherits the resolved archetype, then Default ledge behaviour in Game Settings > Enemies and elements > Enemies. stop turns at edges; fall walks off; fall_when_chasing drops only during a chase. Patrollers turn at walls. Vertical patrols turn at solid floors and ceilings. Ground movers land below; bottomless pits defeat them without loot. Enemy fall gravity (tiles/s²) sets downward acceleration. Enemy On defeat > species sets an optional bestiary identity; blank uses enemy_type before archetype and skin. Untick in_bestiary to exclude this enemy from recording and totals. Enemy On defeat > Defeat flag writes an ordinary saved story flag under every policy; staged gates can count it. On defeat > Respawn selects always, room_reload, save or never; type_default inherits the resolved archetype, then enemy_defaults.respawn_policy (room_reload). always returns on room entry, room_reload on room rebuild, save after Save Point rest, death or load, and never stays defeated through saved Flags. Checkpoints save without reviving save enemies. Save after a permanent defeat in Game Settings makes never defeats durable immediately; otherwise save before dying or quitting. Rank > Champion makes a named fight with optional room seal, bar, music and an added enrage attack. Game Settings > Enemies and elements > Champions sets Health multiplier, Damage multiplier and Engage range (world px). Champion Respawn type_default resolves to never before archetype/project defaults; an explicit repeatable policy still returns, but Champion reward grants directly once in the defeat save even with Save after a permanent defeat off. Unsealed champions heal fully on room exit; player death resets health without repositioning. Boss bars and music take priority. Test helpers 670-671 live in sample_map6 because sample_map5 is full. Enemy elements and Boss damage_affinities offer multi-select weak_to, resist_to, immune_to and vulnerable_to. Enemy damage_type selects outgoing attacks; none inherits the preset. Blank affinities inherit. Enemy status_on_hit and status_chance apply statuses on contact, melee and shots; status_immune on enemies and bosses adds to preset immunities. Freeze stops regular enemies; bosses are immune by default through status_effects.lua. Prepare & Check refreshes type choices from developer/config/damage_types.lua.

Object art states

Link collection-image objects with Class object_art and owner_ref to their gameplay object. Set art_state to default for the unlit torch or inactive checkpoint image, lit for the lit torch image, and active for the current checkpoint image. Only the current respawn point is active: another checkpoint, save point or fast travel station replaces it. Room loading and save reloading restore the picture without feedback. Missing lit or active art keeps the default image unchanged. Torch ignition > allow_extinguish returns to default; starts_lit begins lit. The saved set_flag remembers lighting and is not cleared by extinguishing. Checkpoint activation > trigger_once limits activation, not how long its active art remains. See the creator guide recipe: Make a torch or checkpoint change its look.

Lights, anchors and blocks

Launch Cannon: touch to hold the visible player at its centre. Aim mode fixed uses Angle; sweep ping-pongs through Sweep range at Sweep speed degrees/second. Fire on jump waits for Jump; auto starts flight when Auto delay ends. Launch speed is world px/s; Control lock time blocks horizontal steering; Keep momentum preserves carry. Cooldown starts on firing. Breaks action opens matching Action Barriers during the lock without enemy damage. Linked art follows root rotation. Commented player_settings.launch keys set loaded immunity, pose and the DisplayText button prompt. Keep the whole loaded body and flight clear of hazards and ceilings, provide safe ground and describe one-way progression_links.

Bounce Pad: expand Launch, set Launch angle to 45 for up-right or 135 for up-left, Control lock time in seconds and Keep momentum for carried horizontal speed. Bounce speed is pixels per second. A 90-degree pad keeps the existing upward bounce. Keep the whole player and flight arc clear of hazards and ceilings, provide safe landing ground and describe one-way routes with the map's progression_links.

Hazard or Water Volume: choose rise in Level, then signal or room_enter in Rise start. Rise delay is seconds, Rise speed is pixels per second, and Rise limit is tiles above the drawn top. Deactivate, a safe return, death or room reload restores the drawn level and stops the rise; rise never replays Persist state. Hazards retain contact mode and resistance, use hazard_id as their channel, and level signals no longer disable them. Clear Retract hides tiles and use Level art layer for painted rows. Path motion and Level cannot be combined.

Water Volume: turn Swim enabled off for wading. Swimmers can use Dash under water. To change the underwater dash for the whole game, edit developer/config/swim_settings.lua. With a positive Damage interval, a damaging pool takes health on contact and at each interval without stun or knockback. A zero interval keeps ordinary hits. When two pools overlap, leaving the last-entered pool restores the other pool's waterline, drag and oxygen rules. Swimmers can still steer with an empty oxygen meter. Splash effect treats quick bobs at the surface as one visit. To change the water level, expand Level, choose switch, set Level offset in whole tiles and Level speed in pixels per second (0 is instant). Set Level art layer to decorative painted water; keep floors separate. A Lever or Pressure Plate Target ref picks the volume. Tick the sender’s Persist state to keep the level across room and save reloads. Hazard supports the same switch fields to drain lava.

Background image layers and objects with Class background_visual can opt into stretch_to_fill to widen with the picture; it defaults off.

Set the room map darkness float to 0–1 (1 is fully dark in Light mask mode; Glow only stops at 0.9); absent values use game_config.visual.default_room_darkness. Environment ▸ Light Source adds a radius/intensity-controlled light. Lights reveal the room art near them in Light mask mode. Interaction ▸ Torch (torch_holder) switches a light with Interact: choose starts_lit, require_interact and allow_extinguish, optional labels, sound IDs and set_flag. Paint visible torch art in Tiled. Empty IDs use the placed object.

Navigation ▸ Grapple Point is a small static grapple target without script overrides. Tune the player hook in Project ▸ Game Settings… ▸ Grapple and mark the target with visible anchor art. See the Grappling guide for surfaces, exact shapes and obstruction rules.

Physics ▸ Pushable Block uses a resizable rectangle and captured Tiled art. Walk into it to push, or hold Interact beside it and move to grab and pull. move_embedded_tiles moves that art with the block; mass is emitted into the collision component and gravity_scale controls movement. Set a pressure plate’s allow_world to true to let the block hold it down.

All four templates belong on the top-level templates object layer and bake into editable gameobjects in the room collection.

Button names in text

Write {input:jump} in sign, hint, lore or dialogue text to show the current key or themed controller button, following the device used last and player remaps. Names are Controls row ids or lower-case action names; {input:dash|both} shows both devices. Unknown tokens stay as typed and warn once. Write a hold as Hold {input:grapple}.
